## Cloud prerequisites of the solution (2026-10-09)

- **Managed PostgreSQL quota**: one cluster per fleet (`msp.postgres.count`, 1 per fleet) in the
  control plane's project. The reference tenant's quota was raised on 2026-10-09 (the reference fleet
  and a test fleet use one each); a new fleet needs one free.
- **Control-plane region**: Managed Service for PostgreSQL exists in eu-north1, eu-west1, eu-west2,
  me-west1, us-central1 and uk-south1 only; `control_plane.region` must be one of them
  (`stack/config/variables.tf` validation). eu-south1 cannot host the control plane; it can be a GPU
  region. Owner decision 2026-10-09: no in-cluster database fallback.
- The usual: one project per region, a subnet in each, GPU quotas per platform, network-ssd for
  filesystems, caches and the database disk, one public IP per cluster.
