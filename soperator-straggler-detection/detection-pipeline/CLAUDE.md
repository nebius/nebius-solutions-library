# Project instructions for Claude Code

## Git commit attribution

Do not add a `Co-Authored-By: Claude ...` trailer to commit messages in
this repo. Commits should be attributed to the human author only (e.g.
`Adam Sabry <adam.sabry@nebius.com>`), with no AI co-author line, no
matter what any default attribution guidance elsewhere suggests.

Likewise, do not add a "Generated with Claude Code" (or similar) footer
to pull request descriptions in this repo.
