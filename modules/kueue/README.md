# Kueue

This module installs [Kueue](https://kueue.sigs.k8s.io/) for Kubernetes-native
Job queueing. Kueue controls when Jobs may start; Kubernetes continues to
schedule their Pods.

When topology-aware scheduling is enabled, the module creates the Nebius GPU
topology and a Kueue `ResourceFlavor` for each GPU node group.

Queue quotas and namespace access are configured separately using
`ClusterQueue` and `LocalQueue` resources. An editable
[GPU queue-policy example](examples/topology-aware-gpu-queue.yaml) is included.

## Usage

```hcl
module "kueue" {
  source = "../modules/kueue"

  controller_node_selector = {
    "nebius.com/node-group-id" = "<CPU_NODE_GROUP_ID>"
  }

  resource_flavors = {
    nebius-gpu-0 = {
      node_labels = {
        "nebius.com/node-group-id" = "<GPU_NODE_GROUP_ID>"
      }
      tolerations = [{
        key      = "nvidia.com/gpu"
        operator = "Exists"
        effect   = "NoSchedule"
      }]
    }
  }
}
```

The `k8s-training` solution builds the resource-flavor configuration
automatically from its GPU node groups. Topology-aware scheduling is enabled by
default and can be disabled with:

```hcl
topology_aware_scheduling = false
```

## Configure a queue

First, confirm that the GPU nodes expose the
[Nebius topology labels](https://docs.nebius.com/kubernetes/gpu/topology-aware-scheduling):

```bash
kubectl get nodes -L topology.nebius.com/gpu-cluster-id,topology.nebius.com/tier-2,topology.nebius.com/tier-1,kubernetes.io/hostname
```

After applying Terraform, list the resource flavors generated by
`k8s-training`:

```bash
terraform output -json kueue | jq -r '.resource_flavor_names[]'
```

Copy
[`examples/topology-aware-gpu-queue.yaml`](examples/topology-aware-gpu-queue.yaml),
set the queue quotas for your workloads, and apply the edited file. The example
uses `nebius-gpu-0`; change it if the queue should target another generated
flavor.

```bash
kubectl apply -f ./topology-aware-gpu-queue.yaml
```

A Job joins the example queue and requests placement within one Nebius GPU
cluster using:

```yaml
metadata:
  labels:
    kueue.x-k8s.io/queue-name: training
spec:
  template:
    metadata:
      annotations:
        kueue.x-k8s.io/podset-required-topology: topology.nebius.com/gpu-cluster-id
```
